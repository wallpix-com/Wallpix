# WallPix v1 — mobile-friendly marketplace starter

## Run locally
Python 3.10+
pip install -r requirements.txt
python app.py
Open http://127.0.0.1:5000

## Demo owner
Email: owner@example.com

## Included
- Responsive light marketplace UI
- Home, search, categories, photo detail
- Login/register
- Owner dashboard
- Add/delete photos
- Creator upload form
- Basic SQLite database
- Mobile/desktop responsive admin UI
